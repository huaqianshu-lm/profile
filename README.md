# 花千树个人作品站

> 一念生发，千树成花。

花千树是一个以时间轴为核心体验的个人作品站，展示个人在 AI、知识、影像、音乐与产品方向的作品。

站点沿着以下叙事路径展开：

```text
Seed → Grow → Works → Method → Exploring → Ending
```

它不是普通的作品集模板或多页面案例站，而是在一个固定舞台中，让一个想法逐渐生长、落成作品，再回到新的起点。

## 作品

当前作品顺序固定为：

1. **Video Production Harness**：将内容分析、叙事、Scene 脚本、视觉原型、AI 配音、字幕时间线和远程渲染连接起来的 AI 视频生产系统。
2. **Unframed**：一首中文独立摇滚原创音乐，配有本地音频、歌词时间线和频谱播放体验。
3. **Memora**：由 AI 参与维护的本地优先个人知识库，将零散资料整理为结构化知识和可复用输出。
4. **AI Radar**：收集、去重、整理公开 AI 信息源，并转化为中文情报的个人 AI 雷达系统。
5. **Life OS**：连接目标、项目、任务与复盘的个人管理系统，让长期目标落到每周和每天的行动中。
6. **echoline**：面向本地影视材料的字幕驱动英语精听工具，不依赖账号、云同步。

## 技术

- 原生 HTML、CSS 和 JavaScript
- ES Modules
- Canvas 视觉绘制
- 浏览器原生 Media API
- 原生视频与音频播放
- 深色／浅色主题切换
- 响应式桌面与移动端布局

项目不使用 React、Vue、构建工具、包管理器、后端、数据库或 SPA 路由。

## 本地运行

在项目根目录启动一个静态文件服务器：

```bash
python3 -m http.server 8000
```

然后打开：

```text
http://localhost:8000
```

由于页面使用 ES Modules 和本地媒体资源，建议通过本地 HTTP 服务访问，不要直接双击打开 `index.html`。

## 项目结构

```text
├── index.html                  单页站点入口
├── assets/                     视频、音频等媒体资源
├── scripts/                    交互、数据、时间线与作品预览
├── styles/                     页面、舞台、作品与响应式样式
├── PROJECT_HANDOFF.md          设计细节与开发交接说明
├── ROADMAP.md                  当前项目进度
└── drafts/                     本地方案与草稿
```

## 视觉方向

视觉结合东方思考与当代数字感，以留白、细线、节点、网络和柔光构成安静、克制的系统界面。深色与浅色主题共享同一套叙事结构，各个作品保留独立的视觉语言。
